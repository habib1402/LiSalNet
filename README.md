# LiSalNet

Official PyTorch implementation of **“Efficient RGB-D saliency detection via
hierarchical heterogeneous alignment with parallel focus units”**, published in
*Pattern Recognition*, 184 (2027), 115292.

[Paper](https://doi.org/10.1016/j.patcog.2026.115292) ·
[Release assets](https://drive.google.com/drive/folders/1x7qqC_t9E4M1e5Dpu5na4FOVPDFjNJcs?usp=sharing) ·
[GitHub Releases](https://github.com/habib1402/LiSalNet/releases) ·
[Citation](#citation)

LiSalNet is a compact RGB-D salient-object detector built around a MobileNetV2
RGB encoder and a dedicated depth encoder. Level-specific fusion uses Modality
Alignment Networks (MAN) at low/high levels and a Dilated Perception Module
(DPM) plus Symmetric Fusion Block (SFB) at the intermediate level. Parallel
Focus Units (PFU) refine each scale before top-down aggregation by the
Sequential Feature Decoder (SFD).

## Published results

The main paper results use grayscale pseudo-depth generated by Depth Anything
V2-Large for both training and testing. F- and E-measures are maxima over
thresholds.

| Dataset | MAE ↓ | S-measure ↑ | max F ↑ | max E ↑ |
|---|---:|---:|---:|---:|
| NJU2K | 0.032 | 0.921 | 0.927 | 0.955 |
| NLPR | 0.022 | 0.932 | 0.923 | 0.965 |
| STERE | 0.033 | 0.918 | 0.917 | 0.953 |
| SIP | 0.045 | 0.890 | 0.907 | 0.935 |
| DES | 0.017 | 0.941 | 0.943 | 0.976 |

| Params | Model payload | GMACs | GFLOPs | Latency | FPS | Peak activation VRAM |
|---:|---:|---:|---:|---:|---:|---:|
| 3.98M | 15.39 MiB | 1.28 | 2.57 | 8.84 ms | 113.2 | 21.5 MiB |

Efficiency was measured at 320×320, batch size 1, FP32 on one RTX 4090;
pseudo-depth generation, preprocessing, transfers, and file I/O are excluded.
GMACs are reported by THOP and GFLOPs use the paper's `2 × GMACs` convention.
See [the reproducibility notes](docs/REPRODUCIBILITY.md) for exact definitions,
software versions, checkpoint selection, and the single-checkpoint baseline.

## Installation

Python 3.8+ is supported. Install a PyTorch build appropriate for your CPU or
CUDA environment first, then install the remaining packages:

```bash
git clone https://github.com/habib1402/LiSalNet.git
cd LiSalNet
python -m pip install -r requirements.txt
```

All commands below are run from the repository root.

## Data preparation

The paper trains on 1,485 NJU2K and 700 NLPR images and evaluates on NJU2K-test,
NLPR-test, SSD, STERE, SIP, and DES. Datasets are not redistributed here; obtain
them from their original sources.

Create one manifest per split. Each nonempty line contains an RGB path and a
mask path separated by whitespace:

```text
NJU2K/RGB/0001.jpg NJU2K/GT/0001.png
NJU2K/RGB/0002.jpg NJU2K/GT/0002.png
```

The default manifest names are:

```text
NJU2K_NLPR_train.txt
NJU2K_test.txt
NLPR_test.txt
SSD.txt
STERE.txt
SIP.txt
DES.txt
```

Paths may be absolute or relative to `--data_dir`. Legacy manifests whose
root-relative entries begin with `/` are also accepted. For every RGB image,
LiSalNet expects an adjacent pseudo-depth map named `<image_stem>_depth.png`.

### Generate the paper pseudo-depth

Clone the official [Depth Anything V2](https://github.com/DepthAnything/Depth-Anything-V2)
repository and download its `depth_anything_v2_vitl.pth` checkpoint. The wrapper
below reproduces the experiment settings: ViT-L, input size 518, per-image
min–max normalization, and one-channel grayscale PNG output.

Depth Anything V2's authors license the Base/Large/Giant model weights under
CC-BY-NC-4.0. The ViT-L checkpoint is not redistributed by this repository;
download and use it subject to its upstream license.

```bash
python tools/generate_pseudo_depth.py \
  --data_dir /path/to/data \
  --lists NJU2K_NLPR_train NJU2K_test NLPR_test SSD STERE SIP DES \
  --depth_anything_root /path/to/Depth-Anything-V2 \
  --checkpoint /path/to/depth_anything_v2_vitl.pth
```

Existing depth files are preserved unless `--overwrite` is supplied.

## Pretrained weights and prediction maps

Download the checkpoints, prediction maps, and checksum manifest from the
[public Google Drive folder](https://drive.google.com/drive/folders/1x7qqC_t9E4M1e5Dpu5na4FOVPDFjNJcs?usp=sharing).
The primary weight is the same 3.98M-parameter checkpoint evaluated on all six
datasets without benchmark-wise selection. Paper-result run weights and the
published PNG prediction maps are provided separately because the paper reports
the best of six independent runs for each benchmark. The exact mapping is in
[checkpoints/README.md](checkpoints/README.md).

Large prediction archives should not be committed to Git. Retain the published
filenames and use the supplied `SHA256SUMS` file to verify downloads.

## Inference and evaluation

Generate P1 saliency maps at original image resolution:

```bash
bash test.sh checkpoints/LiSalNet_single_checkpoint.pth /path/to/data \
  --lists NJU2K_test NLPR_test SSD STERE SIP DES \
  --savedir maps/LiSalNet
```

Use `--gpu False` for CPU inference. The command also prints the legacy float-map
MAE/max-F values and writes `evaluation.json`. For the complete saved-PNG metric
set (MAE, S, max/mean/adaptive F, max/mean/adaptive E, and weighted F), run:

```bash
python tools/evaluate_maps.py \
  --data_dir /path/to/data \
  --pred_root maps/LiSalNet \
  --output maps/LiSalNet/evaluation_full.json
```

Only P1 is used for final evaluation. RGB and depth are resized to 320×320 for
inference; P1 is then bilinearly resized to the original RGB resolution.

## Training

```bash
bash train.sh /path/to/data --savedir checkpoints/my_run
```

The default reproduces the paper schedule: 150 epochs, batch size 10, Adam with
learning rate `1e-4`, betas `(0.9, 0.99)`, weight decay `1e-4`, 200-iteration
warm-up, and polynomial decay with power 0.9. Every epoch contains full passes
at 256, 288, and 320 pixels. ImageNet initializes the retained MobileNetV2
features; pass `--no_imagenet` to disable downloading/cached loading.

Fresh training never selects on a benchmark test set. Without `--val_list`, the
final weights are saved as `model_final.pth`. If a disjoint held-out training
validation manifest is available, use:

```bash
bash train.sh /path/to/data \
  --train_list NJU2K_NLPR_train \
  --val_list NJU2K_NLPR_val \
  --savedir checkpoints/my_validated_run
```

Use `--weights` for model initialization and `--resume` only for a complete
training checkpoint produced by this release.

## Checkpoints from the original implementation

The RGB encoder ends at MobileNetV2 feature block 17. The classification-only
320→1280 terminal block is absent. Older LiSalNet weights can be converted
strictly; only the six known tensors/buffers of that terminal block are removed:

```bash
python tools/convert_checkpoint.py old_model.pth converted_model.pth
python verification/verify_model.py --checkpoint converted_model.pth --device cpu
```

The converter rejects missing, unexpected, or shape-mismatched active weights.
Legacy optimizer state is intentionally not migrated.

## Profiling

```bash
python params.py
python profiling.py \
  --checkpoint checkpoints/LiSalNet_single_checkpoint.pth \
  --device cuda:0 --height 320 --width 320 --batch_sizes 1 \
  --warmup 60 --runs 300 --output profiling.json
```

The published FPS is the reciprocal of synchronized median latency. Run three
fresh processes and report the median run when reproducing the paper value.
